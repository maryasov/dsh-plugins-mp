# dsh-plugins-mp

Плагин маркетплейса для DeepSeek Harness: кастомная вкладка-каталог в
[DSH better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar) + MCP-сервер
(`mp_search`, `mp_similar`, `mp_details`, `mp_install`, `mp_trending`) поверх API
[dsh-plugins.vue-z.com](https://dsh-plugins.vue-z.com).

Статус: в разработке (этап 8 плана). Исходники площадки — приватный репозиторий
`maryasov/dsh-plugins-marketplace`.
